# 领读人发现首页 · 独立分支

分支：`feature/leader-discovery`。基于已确认版本 `241ff6eff55f0255b0a406db35bf61756b4b8881` 新建，不修改原工作目录或原版线上主分支。

## 页面与路径

| 入口 | 路径 | 行为 |
|---|---|---|
| 新首页 | `index.html` | 宣传开场、搜索、三个固定推荐、领读人选择、对应读书会 |
| 信息流 | `feed.html` | 原信息流的完整数据、日期、卡片与交互 |
| 读书会 | `club.html` | 原有我的读书会 |
| 我的 | `me.html` | 原有个人页和设置 |

初始化结束、已初始化账号登录均进入 `feed.html`。信息流详情返回信息流；从新首页进入的书刊、文章等资源附带 `from=discover` 和 `leader`，返回后保留所选领读人。桌面与手机主导航均为四项；手机使用现有玻璃胶囊语言的底部四 Tab，二级阅读页面保留返回操作。

## 设计与内容

参考 https://www.pexels.com/zh-cn/ 的大幅开场、搜索入口、固定推荐、分类切换和内容网格结构；分类对应领读人。沿用既有 Figtree / PingFang SC、深色文字与胶囊、白卡、浅灰背景、圆角及轻阴影。内容模块为领读推荐、精选图书、精选杂志、播客和精选文章，不增加 footer。

使用既有三位领读人元数据、书刊目录和文章/播客样例，各领读人的顺序、推荐及内容组合独立。它们是同一项目的界面内容组合，不表示新增抓取或人工核实了这些领读人的实际策展。所有阅读目的地继续使用现有详情组件，不重做阅读器。所有图片复用已有共享图床；分支没有新增图片字节。

实现位于 `_app/`。仓库根 HTML 维持现有发布版资源路由；`asset-worker.js` 继续解析共享图片地址。

## 本地预览

```sh
python3 scripts/serve-discovery.py --host 0.0.0.0 --port 8898
```

电脑：http://127.0.0.1:8898/ 。预览直接服务 `_app/`，不依赖 Service Worker，所以同一局域网的手机可用电脑 IP 加端口访问。图片优先读取原项目已经存在的共享图片兼容入口；原项目目录不存在时，跳转至已有独立共享图床。没有复制图片库或修改原项目。
